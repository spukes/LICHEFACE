# LICHESS DESKTOP CLIENT

Aplicación para escritorio de Windows que conecta a tu API de Lichess.org para jugar online en modos Rápido y Clásico.

También permite jugar contra stockfish.

Cambia entre cuatro interfaces diferentes para recordar la época retro del ajedrez informático:

* CGA
* VGA
* Monocromo
* Fósforo verde
